## 2025-01-20 - Global Keydown Listener for Non-Semantic Buttons
**Learning:** This app heavily uses non-semantic `<i>` tags (Material Icons) as primary action buttons (`.action-icon`) instead of native `<button>` elements. This breaks default keyboard accessibility (Enter/Space to activate) and focus states.
**Action:** When adding accessibility to these non-semantic components, adding `role="button"` and `tabindex="0"` is necessary but not sufficient for interaction. Instead of adding inline `onkeydown` handlers to every single icon (which inflates the DOM), a global `keydown` event listener attached to `document` checking for `e.target.matches('.action-icon, .module-card, [role="button"]')` efficiently provides keyboard interaction (Enter/Space to click) across the entire application without needing to refactor the HTML structure. Always pair this with `:focus-visible` styles on those classes to restore visual keyboard focus indicators.
