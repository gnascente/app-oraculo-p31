## 2024-05-24 - Accessibility Keyboard Events on Icons\n**Learning:** The application heavily uses non-semantic `<i>` tags (Material Icons) as primary action buttons, but these buttons lack `role="button"`, `tabindex="0"`, `aria-label`, and keyboard listeners for 'Enter' and 'Space'. \n**Action:** Add accessibility attributes to these icon tags and a global keyboard event listener to handle activation.
