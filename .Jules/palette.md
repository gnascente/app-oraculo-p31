## 2026-09-25 - [Accessibility] Pattern for non-semantic interactive icons
**Learning:** This app heavily uses non-semantic `<i>` tags (Material Icons) as primary action buttons instead of `<button>` elements. To make them accessible without refactoring the entire HTML structure and potentially breaking existing styles, a combination of `role="button"`, `tabindex="0"`, `aria-label`, and a global `keydown` event listener in `index.html` (listening for Enter/Space on elements with `role="button"` or `.action-icon`) is an effective and maintainable pattern. Adding `:focus-visible` ensures keyboard users can see where they are without disrupting mouse/touch interactions.
**Action:** When adding new interactive icons in this application, apply the `.action-icon` class, `role="button"`, `tabindex="0"`, and `aria-label` or `title`. The global listener will automatically handle keyboard accessibility. Avoid adding inline `onkeydown` handlers to individual elements.
