## 2024-11-20 - Global Keydown Listener for Non-Semantic Buttons
**Learning:** The application heavily uses non-semantic `<i>` tags (Material Icons) and `<div>` elements as primary action buttons (e.g., in the header and menus). This breaks native keyboard accessibility because these elements do not receive focus or trigger on Enter/Space out-of-the-box.
**Action:** Implemented a scalable pattern: a global `keydown` event listener in `index.html` that listens for Enter/Space keys and triggers `.click()` on any focused element with `role="button"`. This means future UI modifications only need to add `role="button"`, `tabindex="0"`, `title`, and `aria-label` to become fully keyboard accessible, without needing inline `onkeydown` handlers everywhere. Added focus-visible styles in CSS to visually indicate focus.
