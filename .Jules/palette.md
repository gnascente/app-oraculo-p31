## 2026-10-20 - Keyboard Accessibility for Non-Semantic Buttons
**Learning:** This app heavily relies on non-semantic `<i>` (Material Icons) and `<div>` elements as primary action buttons (e.g., in the header and home grid). This makes them inherently inaccessible to keyboard users as they cannot receive focus or be activated via standard keyboard interactions.
**Action:** Always add `role="button"`, `tabindex="0"`, and `aria-label` attributes to these non-semantic interactive elements. To ensure activation parity with native buttons, implement a global `keydown` listener that intercepts 'Enter' and 'Space' keypresses on elements with `role="button"` and programmaticly triggers their `click()` method. Additionally, define a global `[role="button"]:focus-visible` CSS rule to provide clear visual feedback during keyboard navigation.
