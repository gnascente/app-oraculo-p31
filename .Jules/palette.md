## 2026-10-11 - Add ARIA Labels and Keyboard Accessibility\n**Learning:** The application heavily uses non-semantic `<i>` and `<div>` tags as primary action buttons without ARIA roles, tabindex, or keyboard support, which is a significant accessibility issue.\n**Action:** Add `role="button"`, `tabindex="0"`, and `aria-label` attributes to these elements, along with a global `keydown` event listener for 'Enter' and 'Space' activation, and focus-visible styling.
